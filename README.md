## → The short version

I'm a **Full-Stack Developer** and **AI Engineer**, most at home designing APIs, shaping database schemas, and thinking through system architecture — but I like a clean, intuitive frontend too, so I don't hand that part off. Before any of that, I was climbing utility poles and babysitting Cisco routers as a **Network Operations Engineer**. Somewhere between incident tickets and load balancers I got curious about what was *running* on the other side of the network, and that curiosity turned into a career.

Since then: a stint running my own business, a bootcamp I walked out of with two "Best Capstone" awards, a banking API migration that taught me to respect production, and a current role architecting an ERP from the ground up. I also run a **home server** where side projects go to be born (and occasionally to die quietly in a Docker container).
